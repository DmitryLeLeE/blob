# BLOB · Слизевик: разум без мозга

Интерактивный 3D-атлас о *Physarum polycephalum*: гранж-журнал 90-х, VHS и живая GPU-симуляция слизевика.

**Сайт:** https://dmitrylelee.github.io/blob/

- `index.html` — текст глав и вкладышей;
- `style.css` — вёрстка, гранж и VHS-фактура;
- `main.js` — агентная модель Physarum (Jones, 2010) на Three.js, пост-шейдер «VHS + ксерокс» / «микроскоп», опыты «Лабиринт», «Токио», «Сделай свою сеть».

Сборки нет: Three.js подключается через import map с jsDelivr. Для локального запуска подойдёт любой статический сервер, например `npx serve .`.

Контуры суши — Natural Earth (через world-atlas). Источники фактов перечислены во вкладыше «Е».
